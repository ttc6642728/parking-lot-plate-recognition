## 一、致命问题（会导致崩溃 / 功能完全失效）

| # | 位置 | 问题 | 修复 |
|---|---|---|---|
| 1 | `auth/auth_manager.py` | 单例 `__init__` 每次实例化都把 `current_user` 重置为 `None`。而 `get_current_user()` 内部就是 `AuthManager()`，等于每次取用户都把登录态清空 | 在 `__new__` 中初始化状态，`__init__` 加 `_initialized` 守卫，只初始化一次 |
| 2 | `ui/record_widget.py`<br>`ui/member_widget.py`<br>`ui/blacklist_widget.py` | 对 `sqlite3.Row` 调用 `.get()`，而 `Row` 不支持 `.get`。数据库一有数据，三个页面刷新即抛 `AttributeError`，主窗口直接打不开 | 在数据出口统一转换：`db/database.py` 的 `query_all` 改为返回 `[dict(r) for r in ...]`，一处改动修好全部调用方 |
| 3 | `config.py` | `DEMO_MODE = True` 默认开启，识别失败时随机编造车牌并提示"识别成功" | 改为 `False`，并在注释与文档中说明答辩临时开启的方式与风险 |
| 4 | `core/parking_lot.py` | 无车位时 `return "", False, "no_spot"`（3 元组），调用方按 2 元组解包 → `ValueError` | 统一返回 `("", False)`，并补充类型注解与注释 |

### 连锁修复（第 1 条的连带影响）

登录态被清空导致 `MainWindow.apply_role_permissions()` 中 `user is None` 直接 `return`，
**两级权限完全没生效**（操作员也能进会员管理 / 黑名单 / 停车记录），
同时 admin 登录后会员页、黑名单页的增删按钮全部是灰色。
第 1 条修复后，权限与按钮状态均恢复正常。

## 二、识别链路问题（实测发现）

| 问题 | 表现 | 修复 |
|---|---|---|
| Tesseract "能报版本但识别不了" | `get_tesseract_version()` 正常，实际识别抛 `Illegal byte sequence`（安装路径含中文），而模板 OCR 只在 Tesseract 完全不可用时才加载 → 识别彻底失效 | ① `OcrRecognizer` 初始化时用一张小图做**真实自检**，失败即标记不可用；② 模板 OCR **无条件加载**作为兜底 |
| OCR 优先级与文档相反 | README 写"内置模板 OCR 优先"，代码却让 Tesseract 优先。实测把 `粤C3Q8L1` 识别成 `ZCSQSE` | 翻转为「模板 OCR 主 + Tesseract 兜底」，并用 `_validate_plate` 判定是否采纳结果 |
| 车牌第 2 位限制过严 | `_validate_plate` 只允许 `A-H`，`京N12345`、`京P88888` 等真实号段被判非法 | 放开为 `A-Z`，并新增公开接口 `core.validate_plate` 供 UI 复用 |
| 三个页面各建一个识别器 | YOLO 模型被加载 3 次，内存与启动时间浪费 | 新增 `PlateRecognizer.shared()` 进程内单例，识别/入场/出场共用 |
| YOLO 权重路径错位 | `config` 指向 `models/yolov8n.pt`，文件却在根目录 → 每次启动尝试联网下载，根目录残留 4.2MB `.part` 残骸 | 权重移入 `models/`，删除下载残留，`.gitignore` 增加 `*.part` |

## 三、业务逻辑问题

| 问题 | 表现 | 修复 |
|---|---|---|
| 会员折扣从未生效 | `compute_fee` 的 `member_discount` 默认值为 `1.0`，恰好满足 `0 < d <= 1` 的合法性判断，实际乘了 1.0。界面却显示"享折扣" | 默认值改为 `None` 表示"未指定"；`None` 时回退 `config.MEMBER_DISCOUNT`。出场结算时传入 `members.discount` |
| 统计口径打架 | 车次按 `entry_time` 分组、营收按 `exit_time` 求和，两个数字永远对不上 | 新增 `ParkingRecordDAO.daily_stats()`，用一条 SQL 把两张汇总表按日期对齐；界面汇总与图表统一取该结果 |
| 删除记录不释放车位 | `used_spots` 只增不减，车位被永久占死 | 删除前判断 `exit_time IS NULL`，是则同步 `on_exit_success()` |
| 统计图中文变方框 | matplotlib 默认字体无中文字形 | `_setup_chinese_font()` 自动选用 Microsoft YaHei / SimHei 等，并关闭 `axes.unicode_minus` |
| 密码明文存储 | 数据库可直接读到明文密码 | 新增 `utils/security.py`（PBKDF2-SHA256 加盐，26 万次迭代）；老数据登录成功后**自动升级**为哈希，无需手工迁移 |
| 入场不校验车牌 | 任意字符串都能登记入场 | 增加软校验：格式不标准时弹确认框，可选择继续（不影响演示） |

## 七、遗留说明（非缺陷，答辩时需主动说明）

1. **合成图 100% ≠ 真实场景准确率**
   `data/images` 下是与字符模板同字体渲染的合成车牌，识别率 100% 只证明链路正确。
   真实抓拍受光照、倾斜、污损、运动模糊影响，模板匹配会明显下降。
   建议答辩时诚实说明，并现场用一张真实照片演示，展示失败案例反而更可信。

2. **YOLOv8 用的是 COCO 通用权重**
   不含 `plate` 类别，实际流程是"检出车辆框 → 框内用 OpenCV 二次定位车牌"，
   并非直接检测车牌。文档已按此修正，避免答辩被问到时表述失实。

3. **摄像头识别在主线程运行**
   每 1 秒识别一帧（约 380ms），期间界面会短暂卡顿。
   如需彻底流畅，可将识别移入 `QThread`，属于可选优化项。
