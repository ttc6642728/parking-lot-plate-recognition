# 功能模块说明

## 1. 登录模块
- 账号 / 密码验证（密码以 PBKDF2-SHA256 加盐哈希存储，不存明文）；
- 登录失败给出提示；
- 默认账号：
  - `admin / admin123`（管理员）
  - `operator / 123456`（操作员）
- 进入主窗口后按角色控制导航栏：操作员禁用“停车记录 / 会员管理 / 黑名单”。

## 2. 车牌识别模块

识别流程为**双引擎并行 + 置信度仲裁**：

1. **HyperLPR3**（深度学习）：检测车牌四点 → 透视矫正 → CRNN 整串识别；
2. **内置管线**（传统 CV）：YOLO/OpenCV 定位 → 二值化 → 投影切分 → 字体模板匹配；
3. **仲裁**：比较内置管线自评置信度。≥0.55 说明模板与输入字体同源，采信内置；
   否则采信 HyperLPR3。两者结果一致时标记为「双引擎一致」。

- **图片识别**：文件对话框选图 → 上述流程 → 回填车牌号；
- **摄像头识别**：后台线程采集，每 1 秒识别 1 帧，识别位置框在实时画面上；
  打开失败会区分"无设备"与"设备被占用"并给出排查建议，
  设备号 / 后端见 `config.CAMERA_INDEX`、`config.CAMERA_BACKEND`；
- **状态显示**：识别成功（引擎 · 置信度 · 耗时）/ 识别中 / 未检测到车牌；
  两引擎结果分歧时状态栏提示「⚠ 引擎结果有分歧」，鼠标悬停可看明细；
- **历史识别记录列表**。

> 识别引擎可在 `config.PLATE_ENGINE` 切换：`auto`（默认，双引擎）/ `hyperlpr3` / `builtin`。
> 准确率评估：`python eval_recognition.py --augment`。

## 3. 入场登记
- 自动 / 手动输入车牌；
- 车牌格式软校验：非标准格式会弹确认框（可选择继续，避免影响演示）；
- 自动分配空闲车位（A001 起递增）；
- 写入 `parking_records`，剩余车位 - 1；
- 停车场已满时弹窗“停车场已满，禁止入场”；
- 自动识别会员 / 黑名单。

## 4. 出场结算
- 根据车牌查找最近未结算的入场记录；
- 调用计费模块：
  - 小型车 2 元/小时、大型车 4 元/小时；
  - 不满 1 小时按 1 小时计费（超 1 小时零 1 秒按 2 小时）；
  - 会员折扣取 `members.discount`（新增会员时默认 0.8，即 8 折）；
    该字段缺失时回退到 `config.MEMBER_DISCOUNT`（默认 0.5）；
- 写回出场时间、时长、费用；
- 剩余车位 + 1。

## 5. 停车记录管理（管理员）
- 表格展示所有记录；
- 按车牌模糊查询、时间段筛选、仅看在场的；
- 导出 Excel / CSV；
- 删除单条记录（管理员权限）——若删除的是**在场未结算**记录，会同步释放车位。

## 6. 会员管理（管理员）
- 录入会员车牌、姓名、电话、有效期、折扣；
- 自动判定车辆是否会员（在 `entry_widget` 中生效）；
- 修改 / 删除 / 续期。

## 7. 黑名单管理（管理员）
- 新增 / 删除黑名单；
- 车辆入场时实时检查并弹窗预警。

## 8. 数据统计与可视化
- 按天统计：车流（柱状）+ 营收（折线）；
- 显示总车位数 / 已用 / 剩余；
- 一键导出 Excel / CSV。
