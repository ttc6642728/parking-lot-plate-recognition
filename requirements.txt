# 车牌识别与停车场管理系统 —— Python 依赖清单
#
# 已验证环境：Windows 11 + Python 3.12.10（版本号见各条注释）
# 安装：pip install -r requirements.txt
#
# 说明
#   1) 识别采用双引擎：HyperLPR3（ONNX 推理）+ 内置传统管线，
#      两者通过置信度仲裁，缺任一仍可运行。
#   2) numpy 必须是 2.x：opencv-python 4.10 起在 Python>=3.9 上要求
#      numpy>=2。旧清单写 "numpy<2.1" 会与新版 opencv 冲突，
#      导致 pip 回溯到很旧的 opencv 或直接解析失败。
#   3) ultralytics 会连带安装 PyTorch（Windows 上约 2 GB），
#      因此默认注释掉。缺少时 yolo_detector 自动改用 OpenCV 定位，
#      而真实车牌走 HyperLPR3 自带检测头，本就不经过该路径。
# =====================================================================
